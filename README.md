# Recycle Bin Emptying Tool

This is a simple Python GUI app that empties the Windows Recycle Bin by clicking a button.

## Language Used
Python

## Libraries Used
- tkinter
- winshell

## File
- recycle_bin_gui.py

## How to Use
Run the Python file on a Windows computer and click the "Empty Recycle Bin" button.

## Note
If winshell is not installed, type:

pip install winshell
